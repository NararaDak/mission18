1. 로그인 상태 아닐경우에 로그인 화면만 나타난다.(단 이때에 영화 목록/리뷰목록 은 보이지 않는다.
2. 로그인 화면에서 로그인이나 확인을 눌러야 로그인을 진행 한다.
3. 정상 로그인이 돼면, 로그인 탬이나 라디오 버튼은 없고, 영화목록/리뷰목록이 나타난다.

4. 로그 아웃 기능도 넣을것.
5. 로그인 화면에서 회원 가입 링크를 넣고, page 밑에  add_user.py 에서 처리 할것.
6. 영화/리뷰는 자기가 추가한 것만 수정/삭제 할수 있도록 할것.

7. 로그인 화면이 처음 접속하면 너무 크다.(가로 화면에 꽉참) 적당한 크기로 고정.
8. 관라지라는 이름으로 접속 했을때, 관리자접속중 과 로그아웃 버튼이 너무 떨어져 있음.

9. 영화 삭제후에 제대로 화면이 안나타나다가 새로고침 하면 다시 로그인하게 되고  삭제된 영화가 없어지는 것이 확인됨. 더 좋은 방안이 있는지 검토/구현 할것.

10. 리뷰 추가/수정 시에는 작성자가 나오지 않아야 한다. 로그인한 사용자의 이름이 자동으로 들어가야 한다.(수정 안됨)

11.영화/리뷰 수정/삭제는 본인만 할수 있도록 할것.
